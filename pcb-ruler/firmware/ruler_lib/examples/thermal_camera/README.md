# ME218 PCB Ruler - Thermal Camera

This sketch creates a thermal camera utilizing a thermal sensor and 1.44" tft. This sketch was extended from Adafruit's examples for their AMG88xx GridEYE 8x8 IR camera but made to work with a different tft display.
