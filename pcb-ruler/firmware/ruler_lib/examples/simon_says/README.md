# ME218 PCB Ruler - Simon

This sketch is a working example of the Simon game by Milton Bradley (now Hasbro). The game begins by pressing the center button. 
Each round, a colored led will light and the associated tone will play. The player then copies the pattern by pressing the button associated with the led.
The next round will play back the previous light, along with another one. The player copies the pattern again, adding in the new one at the end.
As rounds go by, the speed of the pattern presentation will increase. There are 30 rounds of play. If the player enters an incorrect entry, the game is over.
