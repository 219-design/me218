# ME218 PCB Ruler - ToF Ruler

This sketch creates line of sight digital ruler utilizing a time of flight sensor. Distances measured from the sensor will be displayed on the OLED screen. Pressing the button will change units from imperial to metric. Distances greater than 5400mm are outside of the sensors operating range and will not be accurate.
